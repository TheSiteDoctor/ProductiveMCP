Preview what the ProductiveMCP task templates will create in a Productive project, without applying anything. Task lists are project phases, top-level tickets are Features (epics), and their children are the tasks. Tick the templates you want to stack: lists with the same name merge, and where an earlier template already created a ticket with the same title, it is reused and only the missing children are added, exactly as productive_apply_task_template behaves.

    How to read this

    Each box is a Productive task list (a project phase). Rows inside are tickets; an arrow means the ticket has children or a description, created with a parent relationship exactly as shown. The phase names come from the foundation_list, delivery_list and launch_list variables, so they can be renamed per project. A milestone marks the end of its phase, so tickets added by later templates are placed above it. Repeated tickets, such as a Show & Tell per sprint, are shown once per copy; change sprint_count to see the effect. Estimates are the template's estimate_minutes, set as the initial estimate in Productive. Due dates are relative to the day the template is applied.

    This page is generated from the template files. After editing a template, run npm run templates:report to rebuild it.
